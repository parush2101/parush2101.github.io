Software

I am the co-creator of two packages for difference-in-differences methods, with others in development. See each package's documentation for instructions.

staggeredGMM RStata

GMM Estimation of Treatment Effects Under Staggered Adoption

Companion to Estimating Treatment Effects under Staggered Timing and Non-Spherical Errors (with Rishabh Bijani).

R

install.packages("staggeredGMM")
View on CRAN Reference manual Source on GitHub

Stata

ssc install staggeredgmm
